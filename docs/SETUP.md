# セットアップ手順

所要時間の目安：**認証情報の取得 15分 / 公開まで 30分**。

---

## 1. 楽天ウェブサービスのアプリを登録する

APIキーはここで取ります。楽天会員IDが必要です（無ければ先に会員登録）。

1. <https://webservice.rakuten.co.jp/> を開き、楽天会員IDでログインする
2. 「アプリID発行」からアプリを新規登録する
   - **アプリ名**：サイト名（例：楽天ランキング速報）
   - **アプリURL**：公開予定のURL。Cloudflare Pages なら `https://<プロジェクト名>.pages.dev/`
     （まだ公開していなくても、これから使うURLを入れて構いません）
3. 登録すると **applicationId** と **accessKey** が発行される

> 2026-07-01版の商品検索APIから、`applicationId` に加えて `accessKey` が**必須**になりました。
> 古い記事は `applicationId` だけで動くと書いてありますが、現在は 401 で弾かれます。

登録できるアプリは1開発者あたり5個までです。

## 2. アフィリエイトIDを確認する

アフィリエイトIDは**1開発者につき1つ**で、上のダッシュボードから確認できます。

1. 楽天ウェブサービスのダッシュボードで「アフィリエイトID確認」を開く
2. 20桁の英数字（例：`1a2b3c4d.5e6f7g8h.9i0j1k2l.3m4n5o6p`）をコピーする

**このIDを設定しないと、リンクが通常の商品URLのまま出力され、報酬は1円も発生しません。**
`npm run stats` の「アフィリエイトリンク化率」で設定漏れを検知できます。

## 3. ローカルで動かす

```bash
cp .env.example .env
```

`.env` を開いて、取得した値を書き込みます。

```
RAKUTEN_APPLICATION_ID=（手順1で取得）
RAKUTEN_ACCESS_KEY=（手順1で取得）
RAKUTEN_AFFILIATE_ID=（手順2で取得）
SITE_URL=https://<ユーザー名>.github.io/<リポジトリ名>
SITE_NAME=楽天ランキング速報
```

点検 → ジャンル取り込み → 実行の順に進めます。

```bash
npm run doctor
```

```bash
npm run genres
```

`npm run genres` は楽天APIから実際のジャンル一覧を取得して `config/genres.json` を書き換えます。
**ジャンルIDを手書きしないでください。** IDを1桁間違えると、別カテゴリの商品が「レディースファッション」として黙って公開されます。

不要なジャンルは `config/genres.json` の `enabled` を `false` にすれば外せます。
最初は5〜8ジャンルに絞ったほうが、API呼び出し時間もページ数も扱いやすくなります。

```bash
npm run run
```

```bash
npm run serve
```

<http://localhost:4173> で確認できます。

## 4. Cloudflare Pages で公開する

GitHub Pages はオンラインビジネスや商取引を主目的とするサイトの無料ホスティング用途を認めていません。
アフィリエイトサイトでは利用停止リスクを避けるため、無料枠で静的サイトを公開できる Cloudflare Pages を使います。

具体的な接続手順は **[FREE_OPERATION.md](FREE_OPERATION.md)** を参照してください。

GitHub の **Settings → Secrets and variables → Actions** には次を登録します。

   **Secrets**（値が隠される。認証情報はこちら）
   | 名前 | 値 |
   |---|---|
   | `RAKUTEN_APPLICATION_ID` | 手順1の applicationId |
   | `RAKUTEN_ACCESS_KEY` | 手順1の accessKey |
   | `RAKUTEN_AFFILIATE_ID` | 手順2のアフィリエイトID |

   **Variables**（公開されてよい設定）
   | 名前 | 値 |
   |---|---|
| `SITE_URL` | `https://<プロジェクト名>.pages.dev` |
   | `SITE_NAME` | サイト名 |
   | `SITE_DESCRIPTION` | サイトの説明文 |
   | `SITE_AUTHOR` | 運営者名（任意） |

Cloudflare Pages の接続後、**Actions** タブ →「毎日の自動更新」→ **Run workflow** で手動実行して確認します。

以降は毎日 07:00（JST）前後に自動で走ります。
GitHub の cron は混雑時に遅れることがあるので、時刻は厳密ではありません。

> `.env` は `.gitignore` 済みです。認証情報をコミットしないでください。
> 誤って push した場合は、楽天ウェブサービスのダッシュボードでキーを再発行してください。

## 5. 検索エンジンに登録する

自動更新だけでは誰も来ません。ここまでやって初めて流入が始まります。

1. [Google Search Console](https://search.google.com/search-console) にサイトを登録する
2. `https://<あなたのサイト>/sitemap.xml` をサイトマップとして送信する
3. インデックス状況を数週間かけて確認する

## 報酬についての実際のところ

| 項目 | 内容 |
|---|---|
| 料率 | 商品ジャンルにより **2〜4%** |
| 成果の有効期間 | リンククリック後 **24時間以内に買い物かごへ投入**し、**89日以内に購入完了** |
| 支払い | 月間3,001円超で楽天キャッシュ（受け取りにID連携が必要） |
| 確定タイミング | 売上発生の翌月末に確定、翌々月10日に支払い |

3,000円の商品が売れて報酬は60〜120円です。料率2〜4%なら、**月1万円に届くには月25万〜50万円の承認売上**が必要で、
そこに到達するまでは記事の蓄積と検索順位の獲得に数ヶ月かかります。自動化は「続けるコストをゼロにする」ための仕組みであって、
公開した翌日に収益が立つ仕組みではありません。

## 検索エンジン側のリスクについて（重要）

Google は**自動生成された価値の薄い大量ページ**を「スケーラブルなコンテンツの不正使用」としてランキング対象外にする方針を明示しています。
APIの出力をそのまま並べただけのページは、この判定に該当しやすい種類のものです。

このプロジェクトが差分（順位変動・値下がり・新規ランクイン）を毎日記録しているのは、見栄えのためではなく、
**他所にない情報を持たせるため**です。長期的に流入を伸ばすには、さらに次のどれかを足すことを勧めます。

- ジャンルを絞り、自分が詳しい領域だけを扱う
- 上位商品に自分で書いた短評を加える（`config/` に手書きのコメントを持たせて記事に差し込む）
- 「3ヶ月の価格推移」など、蓄積データでしか書けない切り口を増やす

また、楽天アフィリエイトの規約上、**リンク先の改変やクリックを誘導する偽装表示は禁止**です。
生成されるリンクは `rel="sponsored nofollow"` 付きで、広告表記（景品表示法の指定告示対応）も全ページに出力しています。ここは外さないでください。
